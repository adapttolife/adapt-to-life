What actually broke, because it will explain other odd reviews: public/_headers gives /css/* a five minute freshness plus a one hour stale-while-revalidate window, while HTML is always revalidated. Ship a markup change and a CSS change together, and there is a window where a browser paints new HTML with the last deploy’s stylesheet. Unstyled spans fall back to body size, which is exactly what you saw. The file’s own comment predicted it. The fix is that the review surface should never be the thing that gambles: on staging only, the Worker now marks CSS and JS no-store. Production keeps its cache policy untouched and pays no Worker call for the stylesheet.
